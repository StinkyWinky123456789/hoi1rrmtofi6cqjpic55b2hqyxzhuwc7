# Reel audio

Put royalty-free MP3s in the mood folders: `dramatic`, `hype`, `chill`, `sad`, `funny`.
Claude picks a mood for each Reel; **Swap audio** in the review queue cycles through the tracks in that folder.
If a mood folder is empty, tracks from any folder here are used. With no tracks at all, Reels are silent.

Only use music that is licensed for social media (for example Pixabay Music). Instagram's trending audio
can't be added through the API.
